Privacy policy: TimeTree mirror (personal)

Last updated: 26 October 2026

TimeTree mirror is a private tool used only by its owner, who is also its only user. This policy explains what it accesses and what it does with that data.

What it accesses

  • Google Calendar, through one permission only: https://www.googleapis.com/auth/calendar.app.created. This lets the tool create its own secondary calendar and manage events in calendars it created. It cannot see or change any other calendar, and it has no access to email, contacts, files or any other Google data.
  • One shared TimeTree calendar, read-only, with the owner's own TimeTree account.

What it does with the data

It copies each event's title, times, repeat rule, note, place, link and label colour from that TimeTree calendar into the tool's own Google calendar, and keeps the copy up to date. It never copies attendees, alerts or attachments, never sends invitations, and never writes anything to TimeTree.

Storage and sharing

The tool runs on the owner's private computer and home server. It keeps only the sign-in details it needs and a record of when it last ran. Event content is held in memory while copying and lives only in TimeTree and the owner's Google calendar. Data is not sold, shared with anyone, used for advertising, or used to train AI models.

Google API Services User Data Policy

TimeTree mirror's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can stop the tool at any time and remove its Google access at myaccount.google.com/permissions. Deleting the tool's calendar deletes the copied events.

Contact

Questions about this tool: contact its owner through github.com/JamyPatch44.
